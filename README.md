# 🎬 Movie Recommendation System

A content-based movie recommender system built using the TMDB dataset. The system suggests movies based on similarity in genres, keywords, cast, crew, and overview.

## 🚀 Features
- Personalized movie recommendations
- Content-based filtering approach
- Interactive Flask web interface
- Real-time search and results

## 🧠 Machine Learning Approach
- Data Cleaning & Preprocessing
- Feature Engineering (genres, keywords, cast, crew, overview)
- Vectorization using TF-IDF / CountVectorizer
- Similarity calculation using Cosine Similarity

## 📊 Dataset
- TMDB Movies Dataset (Kaggle)
- Files: `movies.csv`, `credits.csv`

## 🛠️ Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Flask
- Matplotlib / Seaborn

## ⚙️ How It Works
1. Merge movie and credits datasets  
2. Create combined metadata  
3. Convert text into vectors  
4. Compute cosine similarity  
5. Recommend top similar movies  

## 🎯 Learning Outcomes
- Applied NLP in recommendation systems  
- Built end-to-end ML pipeline  
- Integrated ML model with web application
